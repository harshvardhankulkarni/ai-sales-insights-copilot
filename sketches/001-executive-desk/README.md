# Theme A — Executive Desk

## Stance
A calm business briefing. Light, warm, editorial. Reads like a daily
report a manager opens once and scans.

## Key choices
- Layout: KPI cards on top, chart left, chat in a right column.
- Typography: serif headings (Georgia) over a soft neutral background.
- Color: warm paper whites, muted gold accent.
- Interaction: click an example question to see the ask/answer thread.

## Trade-offs
- Strong at: friendly to non-technical readers, feels like a product.
- Weak at: less screen density; the chat column is narrow.

## Best for
- Demo videos and interviews: it looks like a finished product fast.
