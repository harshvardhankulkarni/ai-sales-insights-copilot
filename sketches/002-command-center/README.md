# Theme B — Command Center

## Stance
A dark, tool-first copilot. Chat owns the left column, data lives right.
The model output is the primary surface; the dashboard supports it.

## Key choices
- Layout: two columns, chat left (fixed width), charts right.
- Color: near-black background, GitHub-style grays, green as the accent.
- Type: monospace accents for the brand and numbers.
- Interaction: example questions sit above the chat, one click asks.

## Trade-offs
- Strong at: feels like an AI product, high density, modern.
- Weak at: darker palette, less approachable for casual readers.

## Best for
Interviewers who want to see GenAI thinking, not just a dashboard.
