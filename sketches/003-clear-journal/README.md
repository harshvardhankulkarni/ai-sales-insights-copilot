# Theme C — Clear Journal

## Stance
A single-column editorial page. Headline first, then numbers, then the
chart, then a q-and-a thread. Reads top to bottom like an article.

## Key choices
- Layout: one centered column, story-like flow.
- Typography: serif headings, generous spacing, black-on-white.
- Color: near monochrome with one dark accent.
- Interaction: question chips under the input, thread grows below.

## Trade-offs
- Strong at: maximum readability, mobile-friendly feel, honest clarity.
- Weak at: fewer KPIs visible at once than a dashboard grid.

## Best for
First-time viewers and anyone who wants the grounded story front.
